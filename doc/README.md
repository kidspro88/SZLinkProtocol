# SZLink Micro Air Vehicle Message Marshalling Library

Files:

- **Doxyfile**: Doxygen project configuration file
- **README**: This file
- **szlink_xml_to_markdown.py**: Converts SZLink XML to markdown

Deprecated files

- **szlink.php**: Generates online documentation from SZLink XML - http://mavlink.org/messages/common
  - **szlink_to_html_table.xsl**: XSL transform used by **szlink.php** (Deprecated)
  - **szlink.css**: CSS used by online documentation (Deprecated)


For more information, please visit: https://mavlink.io/en/
